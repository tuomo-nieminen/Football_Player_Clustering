# Football_Player_Clustering
Clustering football players by playing style using 2024/25 season stats.
Course project for CS-C3240 Machine Learning.

Full report: [Stage 2 report](Tactical_Football_Player_Clustering.pdf)

## Dataset
[Football Players Stats (2024-2025)](https://www.kaggle.com/datasets/hubertsidorowicz/football-players-stats-2024-2025) by Hubert Sidorowicz on Kaggle (sourced from FBref).

Download `players_data-2024_2025.csv` and place it in a `data/` folder:

```
data/players_data-2024_2025.csv
```
## How to run
pip install -r requirements.txt
then open ml.ipynb
